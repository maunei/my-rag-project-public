════════════════════════════════════════════════════════════════════════════════
  SECTION 1 — WHAT THE APP DOES
════════════════════════════════════════════════════════════════════════════════

• **Tab 1 — Semantic Search (local + optional Gemini Quick Chat)**
  - PDFs under PAPERS_DIR are chunked, embedded (BAAI/bge-small-en-v1.5), stored
    in ChromaDB (folder chroma_db/).
  - Each search runs **hybrid retrieval**:
      (a) **Semantic:** top-500 chunks by cosine similarity to the query embedding.
      (b) **Keyword:** Chroma `where_document` with `$regex` = `(?i)` + re.escape(query)
          → case-insensitive substring, literal-safe.
  - **Cutoff:** semantic hits are filtered by “Min similarity”; **keyword hits are
    always kept** even below the cutoff.
  - Cards may show keyword badges (keyword-only vs mixed with semantic).
  - **Quick Chat:** multi-turn Gemini (Vertex) using **one best chunk per paper**
    from the current result list (`stream_rag_response(..., preloaded_chunks=...)`).
    Separate history from Deep Chat; clears on a new search.
  - Paper titles link to **http://localhost:8502/...** (local pdf_server.py).

• **Tab 2 — Deep Chat (Vertex AI + full PDFs via GCS)**
  - Selected PDFs are copied to **selected_pdfs/** and can be uploaded to
    **gs://YOUR_GCS_BUCKET/selected/<filename>.pdf**.
  - Gemini reads PDFs via **gs://** URIs (no ~20MB inline limit).
  - **Chat input** is registered before history so the composer stays below the
    latest exchange.

════════════════════════════════════════════════════════════════════════════════
  SECTION 5 — INSTALL FROM SCRATCH (high level)
════════════════════════════════════════════════════════════════════════════════

1. Install Google Cloud SDK: https://cloud.google.com/sdk/docs/install
2. `gcloud init` — log in, select project **YOUR_GCP_PROJECT_ID**.
3. Enable APIs (if not already):
     gcloud services enable aiplatform.googleapis.com storage.googleapis.com \
       --project=YOUR_GCP_PROJECT_ID
4. ADC + quota project:
     gcloud auth application-default login
     gcloud auth application-default set-quota-project YOUR_GCP_PROJECT_ID
5. Create bucket (name must be globally unique — pick your own if taken):
     gcloud storage buckets create gs://YOUR_GCS_BUCKET \
       --project=YOUR_GCP_PROJECT_ID \
       --location=us-central1 \
       --uniform-bucket-level-access
6. Conda env: `conda env create -f environment.yml` then add **google-cloud-storage**
   to pip if missing; `conda activate papers_rag`.
7. `cd` to papers-rag_app; `streamlit run app.py` → http://localhost:8501
8. Sidebar: **Build Index** once; wait for completion.

════════════════════════════════════════════════════════════════════════════════
  SECTION 7 — BILLING NOTE (Vertex vs AI Studio API key)
════════════════════════════════════════════════════════════════════════════════

This app uses **Vertex AI** via `genai.Client(vertexai=True, ...)` and **ADC**.
Charges go to the **Google Cloud billing account** linked to the project (see
Section 2.6).

A **Generative Language / AI Studio API key** uses a separate “prepay” credit
pool. If you point the SDK at `api_key=...`, you may see **429 prepayment
credits** errors even when GCP credits are fine. The current code path expects ADC.

════════════════════════════════════════════════════════════════════════════════
  SECTION 9 — TROUBLESHOOTING (short)
════════════════════════════════════════════════════════════════════════════════

• **ADC errors:** `gcloud auth application-default login` then restart Streamlit.
• **No search hits for a tool name:** rely on keyword pass; lower semantic cutoff
  for conceptual queries only.
• **Upload failures:** check `gcloud storage ls` — file may exist despite UI error.
• **Deep Chat 500:** try fewer/lighter PDFs or exclude a huge file in the prompt.
• **PDF links broken:** port 8502 in use — check pdf_server.PDF_SERVER_PORT.
